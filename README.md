# Digital Love Scrapbook

A personal, warm, and romantic digital scrapbook website built for your special someone.

## Features
- **Responsive & Mobile-first**: Works beautifully on phones, tablets, and desktops.
- **Storytelling Flow**: Smooth transitions and scrolling to guide the reading experience.
- **Data Customization**: Easy to edit without touching HTML/CSS through `js/data.js`.
- **Aesthetic**: Polaroid-style photo galleries, paper textures, and handwritten typography.
- **Background Music**: Optional toggle to enhance the emotional impact.

## How to Customize

All the personal texts, stories, and image sources are stored in a single configuration file.

1. Open `js/data.js`.
2. Replace all the `[PLACEHOLDER]` texts with your own personalized content.
3. **Photos**: Place your photos inside `assets/images/` and update the filenames in `data.js`. 
4. **Music**: Place your background music file in `assets/audio/` and name it `background.mp3`, or update the audio source in `index.html`.

## Deployment
Since this project uses vanilla HTML, CSS, and JS, you can easily host it for free on platforms like:
- [GitHub Pages](https://pages.github.com/)
- [Vercel](https://vercel.com/)
- [Netlify](https://www.netlify.com/)

Simply upload the entire folder, and your scrapbook is live!
